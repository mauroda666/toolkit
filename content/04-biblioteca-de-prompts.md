# 📚 Biblioteca de Prompts reaproveitáveis

Prompts prontos que amarram as ferramentas dos 3 posts. Cole no Claude/ChatGPT.

## Ingestão pro segundo cérebro (padrão Karpathy)
```
Leia o arquivo em raw/{arquivo}. Extraia os conceitos-chave, decisões e dados acionáveis.
Escreva de 8 a 15 páginas wiki curtas e linkadas em wiki/, cada uma com fontes citadas.
Nunca mais releia o arquivo cru. Atualize o MOC correspondente.
```

## Agente de scraping (browser-use / Firecrawl)
```
Objetivo: coletar {campos} de {site}. Navegue, lide com login/paginação, e devolva
JSON estruturado com {schema}. Se houver bloqueio anti-bot, reporte e sugira Scrapling/curl-impersonate.
```

## Pesquisa acadêmica assistida
```
Pergunta: {pergunta}. Use fontes acadêmicas. Traga 5 papers com achado principal,
método e citações. Aponte consensos e divergências. Formato: tabela + parágrafo de síntese.
```

## Curadoria monetizável (Faceless @minarquismo)
```
A partir de {tendência}, gere 3 roteiros curtos (hook + desenvolvimento + CTA),
tom {tom}, prontos pra publicação multimodal. Sugira thumbnail (shots.so/smartmockups).
```
