# 🗺️ MOC — Segundo Cérebro (Claude + Obsidian)

Repositórios que transformam Claude+Obsidian num segundo cérebro. Recomendação do autor: escolha **1 do padrão Karpathy Wiki** (compilador) + **1 do padrão MCP** (ponte).

## Repositórios
- [[claude-obsidian\|claude-obsidian]] — Padrão Karpathy Wiki (implementação mais pura). Ingere um arquivo uma vez e compila 8-15 páginas wiki linkadas. Melhor pra começar. (produtivo, desenvolvimento, analitico)
- [[obsidian-second-brain\|obsidian-second-brain]] — MCP read-write + Skills. 45 comandos, busca híbrida (BM25+embeddings), notas auto-reescritas e agentes agendados que mantêm o vault sozinho. (produtivo, monetizavel, desenvolvimento, analitico)
- [[obsidian-skills-kepano\|obsidian-skills (kepano)]] — Skills prontas do criador do Obsidian. Clona na pasta de skills e registra sozinho. Aposta mais segura. (produtivo, desenvolvimento)
- [[obsidian-skills-qhuang20\|obsidian-skills (qhuang20)]] — Plugin Claude Code com skill llm-wiki (padrão Karpathy) + utilidades. Rápido pra quem vive no Claude Code. (produtivo, desenvolvimento, analitico)
- [[llm-wiki\|llm-wiki]] — Padrão Karpathy puro, 6 comandos. Setup em menos de 5 min. Mínimo viável. (produtivo, desenvolvimento, analitico)
- [[obsidian-claude-code-mcp\|obsidian-claude-code-mcp]] — MCP read-write via API do Obsidian (respeita plugins Dataview/Templater/Excalidraw). (produtivo, desenvolvimento, analitico)
- [[second-brain-mcp-noesskeetit\|second-brain-mcp (noesskeetit)]] — MCP read-only offline com busca semântica. Funciona em Claude Code, Cursor, Zed. (produtivo, desenvolvimento, analitico)
- [[second-brain-mcp-CoMfUcIoS\|second-brain-mcp (CoMfUcIoS)]] — MCP estritamente read-only. Ideal pra quem não quer risco de escrita automática. (produtivo, desenvolvimento, analitico)
- [[obsidian-plugin-skills\|obsidian-plugin-skills]] — Expande as skills do Kepano com adições da comunidade (journal, meeting-notes, book-highlight, spaced-review). (produtivo, desenvolvimento)
- [[MegaMem\|MegaMem]] — MCP + grafo de conhecimento temporal (Graphiti). Rastreia como conceitos mudam ao longo do tempo. 12 graph tools + 11 vault tools. (produtivo, monetizavel, desenvolvimento, analitico)
