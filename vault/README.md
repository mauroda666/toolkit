# Segundo Cérebro — Vault Obsidian

Estrutura pronta para o Obsidian (já instalado no seu desktop). Abra esta pasta como um vault.

## Pastas
- **00-Inbox** — captura rápida, tudo entra aqui primeiro
- **10-Tools** — uma nota por ferramenta (do thread do X)
- **20-Skills** — uma nota por skill/workflow reaproveitável
- **30-Projects** — Equita, MEI Fácil, Quiksilver, BAS Motors, etc.
- **40-Resources** — referências, docs, links
- **50-Daily** — notas diárias / log de interações com LLMs
- **99-Templates** — modelos (use o plugin Templates do Obsidian)

## Fluxo
Captura → Inbox → processa → move pra Tools/Skills/Projects → linka no MOC.
